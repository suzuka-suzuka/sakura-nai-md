1 兑换密钥与套餐权益

第一步：先兑换再接入

付款后请先将发卡获得的 CDK- 兑换码兑换为 skr_ 密钥，再填入你使用的网页、客户端或酒馆插件中。

  1. 复制付款后获得的 CDK- 开头兑换码。
  2. 打开 密钥兑换页 (https://redeem.tenshimomone.com/)，粘贴兑换码并点击 兑换。
  3. 页面会显示接口地址与 skr_... 完整密钥。请务必当场复制保存！ 每枚兑换码只能兑换一次，关闭页面后无法再次查看。
  4. 如果关闭页面前忘了保存密钥，请将 CDK- 兑换码私发给客服，客服可在后台为你找回对应密钥。
⚠️ 填写与保管提醒

在任何工具的 Key / Token 输入框中，只粘贴 skr_ 开头的密钥本身，切勿手动添加 Bearer 前缀。请妥善保管密钥，不要发到公开群聊或截图中外泄。

💡 V5 体力怎么算？为什么标准独享是 5,920 张，而「节约模式」能画 11,840 张？

本站与官网 Opus 总体力额度完全对等，且现已支持 V5 Medium（节约模式）半价体力：

每月约 7,000 张（单张 23 步）
官网 FAQ 中的“每月约 7,000 张”是以单张 23 步估算的。但跑标准 V5 时为了保证最佳细节，大多数人都会拉满到 28 步，实际能画的 28 步张数同样在 5,900 张左右。

选用官方蒸馏加速的 V5 Medium（节约模式） 生成标准小图，每张仅消耗 0.5 张 V5 体力（1 张体力画 2 张）！4 人合租月总可达 2,960 张，单人独享可达 11,840 张！

🎯 两种 V5 模式怎么选：跑标准 V5（≤28 步）每张固定扣 1 张体力，建议直接拉满 28 步拿最高画质，无需降到 23 步；日常快速抽卡、试提示词或酒馆高频配图，强烈推荐切到 V5 Medium（节约模式），每张只扣 0.5 张体力，出图更快且耐画度直接翻倍！

1.2 四条核心扣费与恢复规则

  • 「月卡：V4.5无限小图（无V5体力）」用户： 享 30 天 V4.5 标准小图无限免点生成，不含 V5 体力与点数。生图时请务必将模型选为 V4.5（如 nai-diffusion-4-5-full）；若误选 V5 / V5 Medium 模型或超规格生图会被系统拒绝。
  • 含 V5 体力的 Opus 用户（1天 / 4人 / 单人独享）： 跑 V4.5 小图同样 0 点数 0 体力无限画；跑标准 V5 小图每张扣 1 张 V5 体力，跑 V5 Medium（节约模式）小图每张仅扣 0.5 张 V5 体力。V5 体力按 24 小时周期恢复（不超过存储上限）；若当天 V5 体力刷完，只需把模型切回 V4.5 就能继续免费无限出图！
  • 纯点数档（100点 / 2k点）： 不含无限小图与 V5 体力，生成任何图片均按实际参数扣除点数。
  • 超规格扣点规则： 只要超出小图标准（宽×高 > 1,048,576 像素、步数 > 28 步、或单次批量出图多出的张数），以及 V5 体力用尽后继续强跑 V5，均需消耗账户内的点数（若无点数则会拒绝生成）。

2 网页直接使用

🌟 新手最推荐 · 免安装 · 支持 Vibe
  1. 电脑或手机浏览器打开 星绘在线画图网页 (https://nai.tenshimomone.com/)。
    ↗ 点击打开星绘网页
  2. 在弹出的「连接设置」窗口中，密钥类型选择 Sakura Key（如右图所示）。
  3. 在下方 Sakura Key 输入框粘贴兑换页获得的 skr_ 密钥，点击 连接 / 更新连接。
  4. 连接成功后选择模型（V4.5 月卡用户请选 V4.5 模型；含 V5 体力或点数用户可选 V5 标准模式、V5 Medium 节约模式（小图仅扣 0.5 张体力） 或 V4.5），即可开始生图，支持 Vibe Transfer（画风参考）、图生图、局部重绘等完整功能。
🌐 网络连接小贴士（连不上怎么办？）

本站兑换页、画图网页及接口均支持国内网络直连；但受部分地区运营商网络波动影响，若偶尔遇到网页打不开、连接超时或生图失败，建议开启「魔法 / 梯子（科学上网）」或切换节点后再试，即可恢复顺畅连接。

5 酒馆 SillyTavern 配图接入（四种方案任选其一）

✅ 全部支持 V5 & V4.5

在酒馆中配图只需在下方 4 种方案（5.1～5.4）中任选 1 种 使用即可（无需同时开启多个画图插件）。所有方案均需确保你的酒馆已连好聊天模型（聊天模型负责写回复与生图 Tag，NovelAI 负责画图）。

前置准备 ①：先接通酒馆聊天模型（聊天模型写词，NovelAI 负责画图）

以 DeepSeek 为例：点酒馆顶部的 ① 插头图标 → ② 聊天补全 → ③ DeepSeek，点 ④ 钥匙图标 添加你自己的 DeepSeek API Key，模型选 ⑤ deepseek-flash 后点连接（切勿把本站 skr_ 绘图密钥填进主聊天接口）。

可先发一句「用一句中文描写撑伞走过樱花小巷的旅人」确认能收到回复。添加完绘图密钥后记得切回聊天补全继续对话。

前置准备 ②：如何安装酒馆扩展程序（柏宝绘 / 小白X / 智绘姬共用入口）

  1. 点击酒馆顶部的 ① 扩展程序 图标，再点右上角的 ② 安装扩展程序。
  2. 把所选扩展的 GitHub 仓库地址粘贴到弹窗的 URL 输入框，分支留空，点 只给我安装。
  3. 安装完成后刷新酒馆网页即可启用。

5.1 方案一：酒馆原生出图（补丁） ✅ 支持 V5 & V4.5 · SillyTavern 1.19.1 📖 补丁仓库与撤销说明 ↗

此补丁已在 SillyTavern 1.19.1 验证，为原生图像生成增加 第三方 API URL 和 V5 Full / V5 Curated 模型。配置后可继续使用酒馆原生的 /imagine 命令、自动配图或魔杖菜单出图。

  1. 安装或更新补丁。新旧用户用同一套命令。Windows 下，在酒馆根目录（有 server.js 的文件夹）打开终端并执行下面两行。脚本会自动安装或更新，完成后重启酒馆并刷新网页。
    💻 安装或更新补丁命令（在 SillyTavern 根目录执行）
    ① 第 1 行：下载安装脚本 curl.exe -fL https://raw.githubusercontent.com/suzuka-suzuka/SillyTavern-NovelAI-Relay-Patch/main/install.mjs -o .nai-relay-install.mjs
    ② 第 2 行：运行安装脚本 node .nai-relay-install.mjs
  2. 填写图片地址。点顶部的 ① 扩展图标，展开 图像生成。将 ② 来源 选择为 NovelAI Diffusion，在 ③ 第三方 API URL 中填入星绘接口地址：
    https://relay.tenshimomone.com/
  3. 保存密钥。点顶部的插头图标打开 API 连接，在下拉框选 NovelAI。点密钥框右侧的钥匙图标，再点弹窗右上角的 添加密钥，粘贴兑换得到的 skr_ 密钥并确认（只用来生图时，下方的文本 API「无连接」可直接忽略）。
  4. 查余额并试画。回到图像生成设置，点 查看我的 Anlas。弹出余额即表示验证通过，0 也是有效余额（酒馆显示的 Free image generation: No 来自它对官方订阅标记的判断，实际扣费按本站套餐规则计算）。

    在 模型 下拉框选 NAI Diffusion V5 (Full) 或 NAI Diffusion V5 (Curated)；仅有 V4.5 小图权益的用户选 NAI Diffusion Anime V4.5 (Full)。在角色聊天框执行下方命令即可试画：

    /imagine extend=false cherry blossoms, blue sky

给聊天正文配图

已有一条角色回复时，可在聊天框输入 /imagine last message，让酒馆先根据最近一条消息写提示词，再调用 NovelAI 生图。

想精确控制画面内容时，可先让聊天模型写一行英文 Tag，再用 /imagine extend=false 加上这行 Tag。右图展示了 DeepSeek 根据剧情生成中文配文后，由 NovelAI 在同一段聊天中生成的樱花小巷插图。

在聊天中配图（手动触发 & 自动配图）

1 打开回复的配图入口

先用酒馆聊天模型聊出一条角色回复，点该条 AI 回复右上角的 ① ⋯，再点 ② 调色盘（悬停显示「生成生图 tag」）。

2 点击卡片生成图片

柏宝绘会读取本楼正文并在同一楼插入配图卡片。点卡片上的 ③ 生成图片 等待出图（想逐张确认可先关闭「自动生成图片」）。

3 查看楼层内插图

NovelAI 出图完成后，生成的插图会直接显示在刚才那条角色回复的绘图卡片里。

4 开启全自动配图（可选）

打开柏宝绘 设置 → 自动生成 tag，同时勾选 ① 自动生成 tag 和 ② 自动生成图片，角色每次回复后会自动判断并出图。

7.4 为什么标准独享是 5,920 张 V5？「V5 Medium 节约模式」怎么做到张数翻倍？

不少朋友看过官网 FAQ 提到“Opus 每月可画约 7,000 张 V5 小图”，疑惑为什么本站单人独享标准 V5 算下来是 5,920 张，以及节约模式怎么扣体力。其实本站与官网总体力条完全一样，且开启节约模式后每张仅扣 0.5 张体力：

  • 官网的 7,000 张是以「单张 23 步」计算的： 在官方机制中，23 步消耗的体力较低，28 步消耗的体力较高。但跑标准 V5 时为了画面细节，绝大多数玩家日常都会把步数拉满到免费上限 28 步，官网账号按 28 步一个月实际能出的张数同样在 5,900 张左右。
  • 本站标准 V5 统一按「单张 28 步满步数」实诚折算（每张扣 1 张体力）：
    以 单人独享 Opus（100% 体力档） 为例：
    • 兑换开卡时，直接发放满槽初始上限 1,120 张（刚好等于 7 天的恢复量：160 张/天 × 7 = 1,120 张）；
    • 随后 30 天有效期内，每 24 小时恢复 160 张（30 天共恢复：160 张/天 × 30 = 4,800 张）；
    • 两者相加：160 × (7 + 30) = 160 × 37 = 5,920 张（28 步满步数标准 V5 小图）！4 人合租 Opus（25% 档）等比例为 40 × 37 = 1,480 张。跑标准 V5 小图时（≤28 步），每张固定扣 1 张体力，建议直接拉满 28 步出最高画质，无需委屈降到 23 步。
  • 🌿 V5 Medium（节约模式）每张仅消耗 0.5 张 V5 体力，可用张数直接翻倍：
    V5 Medium（节约模式，nai-diffusion-5-full-medium） 是 NovelAI 官方推出的 14 步蒸馏加速模式。在本站生成符合小图尺寸（≤1,048,576 像素、单次 1 张）的 V5 Medium 图片，每张仅扣 0.5 张 V5 体力（1 张体力可画 2 张）：
    • 体验 1 天 Opus：约 44 张体力 → 全用节约模式可画约 88 张；
    • 4 人合租 Opus 月卡：每日恢复 40 张体力（可画 80 张 节约模式），30 天总计最高可达 2,960 张；
    • 单人独享 Opus 月卡：每日恢复 160 张体力（可画 320 张 节约模式），30 天总计最高可达 11,840 张！
    • 使用小贴士：V5 Medium 官方强制锁定为 14 步 + Euler Ancestral 采样器，且不支持单独的负面提示词框（若需排除特定元素，可在正面提示词中用负权重语法如 -3::hat::）。星绘网页端切换节约模式会自动适配参数；第三方客户端手动选用 nai-diffusion-5-full-medium 时请同步将步数设为 14、采样器选 Euler Ancestral。

7.5 什么时候会扣「点数」？100 点数大约能画几张图？

点数就是账户里的生图钱包余额（类似官网 ImageAnlas），仅在以下 4 种情况扣除：

  1. 使用纯点数套餐（100点 / 2k点）： 无 Opus 会员权益，生成任何图片均按参数扣点。
  2. 生成超规格图片（大图 / 高步数）： 像素超过 1,048,576（如 1024×1536）或步数超过 28 步，不论什么套餐均扣点数。
  3. 单次批量出图（Batch > 1）： 第一张走小图权益，同批次多出来的张数按点数扣除。
  4. V5 体力耗尽后继续强跑 V5： 当日 V5 体力用完后若不切回 V4.5 而继续跑 V5，会自动改扣点数（无点数则拒绝；此时只要把模型切换为 V4.5，就能继续 0 点数无限免费画小图！）。

酒馆不出图 / 聊天报模型错误 检查是否把 skr_ 绘图密钥误填到了酒馆的「主聊天 LLM 接口」里。skr_ 密钥仅填在绘图插件的 NovelAI 渠道中，酒馆聊天仍使用你原本的聊天模型连接。
报 Failed to fetch / Timeout / 网络错误 本地运营商网络波动或局部阻断，开启「魔法 / 梯子（科学上网）」或切换节点后重试即可恢复。
