9.4 为什么官网说 Opus 每月约 7,000 张 V5，而本站独享是 5,920 张？

不少朋友看过官网 FAQ 提到“Opus 每月可画约 7,000 张 V5 小图”，疑惑为什么本站单人独享（100% 满体力档）算下来是 5,920 张。其实两者的总体力条完全一样，只是折算的单张步数基准不同：

  • 官网的 7,000 张是以「单张 23 步」计算的： 在官方机制中，23 步消耗的体力较低，28 步消耗的体力较高。但几乎所有玩家为了画面细节，日常都会把步数拉满到免费上限 28 步，按 28 步去画，官网账号一个月实际能出的张数同样在 5,900 张左右。

9.5 什么时候会扣「点数」？100 点数大约能画几张图？

点数就是账户里的生图钱包余额（类似官网 ImageAnlas），仅在以下 4 种情况扣除：

  1. 使用纯点数套餐（100点 / 2k点）： 无 Opus 会员权益，生成任何图片均按参数扣点。
  2. 生成超规格图片（大图 / 高步数）： 像素超过 1,048,576（如 1024×1536）或步数超过 28 步，不论什么套餐均扣点数。
  3. 单次批量出图（Batch > 1）： 第一张走小图权益，同批次多出来的张数按点数扣除。
  4. V5 体力耗尽后继续强跑 V5： 当日 V5 体力用完后若不切回 V4.5 而继续跑 V5，会自动改扣点数（无点数则拒绝；此时只要把模型切换为 V4.5，就能继续 0 点数无限免费画小图！）。
